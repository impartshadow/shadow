# Contract: research-epistemology

## Type
Post-response guard — deterministic enforcement via `core/contracts.py`

## Trigger
Any response that presents research findings, factual claims, or synthesized analysis
— identified by presence of assertion patterns ("studies show", "research indicates",
"evidence suggests", "the data shows", "X causes Y", "X leads to Y") in contexts
where Shadow is performing research, briefing, or fact-checking.

## Precondition
When a response makes 2+ scientific or factual claims, ALL of the following must hold:
1. A `## Sources` section (or equivalent citation block) is present
2. No claim is asserted at Level 1 confidence if it appears in only one source
3. If contradictory evidence was encountered during research, it is explicitly
   acknowledged in a "What's Uncertain" or equivalent section — not silently omitted

## Enforcement
**Code-enforced** in `core/contracts.py:ResearchEpistemologyGuard` — scans outgoing
research-context responses for citation-absent multi-claim outputs and fires when
no Sources section is present alongside 2+ factual assertion patterns.

## Origin
2026-04-22: arXiv paper (cs.AI) showed that LLM agents executing research workflows
ignore evidence in 68% of traces and revise beliefs on contradiction in only 26%.
Critically, outcome-based evaluation masks this — a clean-looking brief may have
been generated by ignoring contradictory sources entirely. Shadow needed a
process-level gate independent of how good the output sounds.

## Violation recovery
1. Add a `## Sources` section listing every source consulted with one-line descriptions
2. For any claim now at Level 1 confidence, verify it has 2+ independent citations
3. Downgrade single-source claims to Level 2 with explicit caveat
4. If contradictory evidence was found and dropped, surface it in "What's Uncertain"
5. Never finalize a research brief as "Done." until process check passes

## False positive exemptions
- Casual factual statements in non-research conversational responses (no assertion density threshold met)
- Code responses that contain strings matching assertion patterns but are not research outputs
- Responses explicitly marked as "quick take" or "off the cuff" by the user
- Responses inside fenced code blocks (spec text, quoted prior messages)

## Escalation
If this contract fires on more than 2 research outputs in a session, treat as a
calibration incident — Shadow is pattern-matching to plausible conclusions without
grounding in actual multi-source evidence. Slow down, re-run research with explicit
contradiction search ("what is the strongest argument AGAINST this conclusion?").
