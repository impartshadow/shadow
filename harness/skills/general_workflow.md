# General workflow

Follow `AGENTS.md` and the mandate.

1. Resolve the request and target from relevant context; inspect before changing.
2. Execute within authority. Persist corrections through the canonical tools and
   resume the original work. A factual correction requires checking dependent targets.
3. Verify the requested result and report it briefly, including material limits.

Ask only when unresolved ambiguity changes the outcome or authority. Use `rg` for
local search. Load task references as needed; do not require startup rituals,
parallel agents, or a second memory-writing convention.
