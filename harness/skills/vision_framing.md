# Vision framing — Frontier / MTP / north-star proposals

Applies when the user asks a vision-level question: Massive Transformative Purpose,
frontier/north-star framing, mission statements, "what should Shadow become",
"think bigger", 10-year horizon.

## The failure this prevents

First drafts default to positive-expansion phrasing — "Expand what humans and
autonomous intelligence can become together." It reads well and says nothing.
It names no antagonist, no cost, no boundary that gets crossed. the user has
rejected this shape twice (2026-09-02, 2026-09-03).

## Required elements

Every vision-level proposal must name all four before it is shown:

1. **Actor + capability** — who gains what specific power.
2. **The antagonist** — the force, incumbent, or default outcome the vision
   defeats. Not "inefficiency." A named thing that currently wins.
3. **The irreversible tension** — the thing that could be lost in the trade.
   A vision with no downside risk is a slogan.
4. **The transformed world state** — what is concretely true after that is not
   true now. Testable, not aspirational.

## Preserve this shape

> "Give every person machine-scale agency without surrendering sovereignty."

Actor (every person) + capability (machine-scale agency) + tension (without
surrendering sovereignty). the user's response: "Love love love this." When a draft
reaches this density, do not smooth it back toward safe abstraction on revision.

## Anti-patterns — reject the draft and rewrite

- "Expand what X and Y can become together"
- "Unlock the full potential of…"
- "Redefine how the world…"
- Any sentence that stays true if you swap the subject for a different company.
