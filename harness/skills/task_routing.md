# Task routing

Choose references from the actual request, not keywords alone. A repository URL
may be a code task; “model” may not mean visual design. Load only useful workflows:
research, email_triage, echo, design, travel, or the relevant specialist reference.

Use general_workflow for ordinary execution and workflow_composition when durable
dependencies warrant it. Multi-agent research requires delegation authority.
No routing announcement, role quota, or separate classification ledger is required.
